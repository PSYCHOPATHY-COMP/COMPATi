# PSYCHOPATHY.COMP Program Among Male Prison Inmates With Psychopathy (COMPATi)
# A multicentre parallel-group superiority randomised controlled trial (RCT) of PSYCHOPATHY.COMP: A compassion-based psychotherapeutic intervention to reduce psychopathic traits among male prison inmates

# For more information please see the trial registration, which can be found in ClinicalTrials.gov:
ClinicalTrials.gov ID: NCT07481253
LINK: https://clinicaltrials.gov/study/NCT07481253?cond=compati&viewType=Card&rank=1

# Overview
This repository provides public access to the supplementary materials associated with this study
The purpose of this repository is to promote transparency, methodological reproducibility, and accessibility of the study documentation and supporting materials.

# Updates
This repository will be updated throughout the study.
When applicable, changes to the documentation will be tracked through GitHub version control.
For transparency, relevant document versions and their corresponding dates will be maintained.

# Further considerations
No identifiable participant information or confidential research data will be included.
